The SEO section of the Content Editor shows four fieldsets of the module: "Custom values for Open Graph" (formerly "Custom Open Graph tags"), "Open Graph values", "Custom values for schema.org" and "schema.org values". An editor can set the value of any schema.org property of the type of the mapping, which replaces the mapped value in the JSON-LD of the live page. "schema.org values" shows that JSON-LD as formatted JSON. The Facebook, LinkedIn and X share cards have the layout, the colors and the fonts of each network.
